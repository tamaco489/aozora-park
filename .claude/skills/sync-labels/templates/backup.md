## 復元のしかた

ラベル定義を作り直す。

```sh
gh label create {{名前}} --color {{色}} --description "{{説明}}"
```

Issue と PR に付け直す。

```sh
gh issue edit {{番号}} --add-label "{{ラベル}}"
gh pr edit {{番号}} --add-label "{{ラベル}}"
```

改名だけを行った場合、既存の Issue と PR のラベルは自動で新しい名前に追随するため、付け直しは不要。
